# AnyDrag 改进设计文档

日期：2026-05-05
状态：已确认

## 背景

AnyDrag 是一个 Windows 桌面工具，允许用户通过自定义鼠标组合键在窗口任意位置拖拽。当前存在两个体验问题：

1. 使用 Left + Side1 组合时，在浏览器和编辑器中容易误触（触发浏览器后退、拖拽中断）
2. 设置界面视觉效果不够理想

## 改进内容

### 1. 组合键松开宽容窗口

**目标**：解决拖拽过程中误松开导致的中断问题。

**设计**：

在 `MouseHook.cs` 中增加宽容窗口机制：

- 拖拽进行中，松开组合键中的任意一个键时，**不立即结束拖拽**
- 启动一个 300ms 的宽容计时器
- 300ms 内重新按下该键 → 继续拖拽，计时器取消
- 300ms 超时 → 正式结束拖拽
- 同样适用于"几乎完成"状态（只差一个键就满足组合）—— 松开时也给宽容窗口

**300ms 选择依据**：人类快速点击间隔约 100-200ms，300ms 足够宽容又不会让正常操作感觉粘滞。

**涉及文件**：`AnyDrag/MouseHook.cs`

### 2. 界面优化

**目标**：改善设置界面的视觉效果，不改变功能结构。

**设计**：

对 `SettingsForm.cs` 进行以下调整：

**布局改进**：
- 增大窗口整体尺寸，给各区域更多呼吸空间
- 设置项之间加大间距，分组更清晰（组合键设置 / 快捷键设置 / 语言设置）
- 按钮统一样式和大小，对齐方式一致

**字体和配色**：
- 标题使用更大字号，正文使用更清晰的字体
- 背景色改为浅灰白（`#F5F5F5`），避免纯白刺眼
- 按钮使用深色背景 + 白色文字，增强对比度
- 分组之间用淡色分隔线区分

**交互细节**：
- "录制中..." 状态增加更明显的视觉提示（比如按钮变色）
- 当前生效的设置项有高亮标记

**涉及文件**：`AnyDrag/SettingsForm.cs`

## 不在范围内

- 更换默认组合键（保持 Left + Right + Side1）
- 新增功能（窗口吸附、窗口大小调整等）
- 更换 UI 框架（保持 WinForms）
